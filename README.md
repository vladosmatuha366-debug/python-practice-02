# Калькулятор стоимости покупки

## Назначение проекта
Консольное приложение на Python для расчёта стоимости покупки с учётом скидки.

## Какие задачи решает программа
- Запрашивает название товара, цену за единицу и количество.
- Рассчитывает исходную стоимость покупки.
- Автоматически определяет скидку:
  - от 5 000 до 9 999,99 руб. — 5%;
  - от 10 000 до 14 999,99 руб. — 10%;
  - от 15 000 руб. — 15%;
  - менее 5 000 руб. — скидки нет.
- Выводит размер скидки в процентах и рублях, а также итоговую стоимость.
- Дополнительно показывает экономию и цену одной единицы после скидки.
- Позволяет рассчитать несколько покупок за один запуск.
- Проверяет корректность введённых данных.

## Требования
Python 3.8 или новее. Дополнительные библиотеки не нужны.

## Запуск
1. Сохраните файл `main.py`.
2. Откройте терминал в папке с файлом.
3. Выполните команду:

```bash
python main.py
```

На некоторых системах команда может называться `python3 main.py`.

## Как пользоваться
1. Введите название товара.
2. Введите цену одной единицы товара. Можно использовать точку или запятую в дробной части.
3. Введите положительное целое количество.
4. Прочитайте чек с исходной стоимостью, скидкой и итоговой суммой.
5. Ответьте `да`, если хотите рассчитать следующую покупку, или `нет` для завершения.

## Пример работы

```text
=== Калькулятор стоимости покупки ===
Введите название товара: Клавиатура
Введите цену одной единицы товара (руб.): 4500
Введите количество товара (целое число): 3

--- Чек ---
Товар: Клавиатура
Цена за единицу: 4500.00 руб.
Количество: 3
Исходная стоимость: 13500.00 руб.
Скидка: 10%
Скидка в рублях: 1350.00 руб.
Итоговая стоимость: 12150.00 руб.
Вы экономите: 1350.00 руб.
Стоимость одной единицы после скидки: 4050.00 руб.

Рассчитать ещё одну покупку? (да/нет): нет
Спасибо за использование программы!
```
